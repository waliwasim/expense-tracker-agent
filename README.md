# Expense Tracker Agent

AI-powered Expense Tracker with Budget Limits in Pakistani Rupees.

## Quick Start

1. Install dependencies:
```bash
npm install
```

2. Create `.env.local` file and add your Groq API key:
```
GROQ_API_KEY=gsk_your_key_here
```

Get key: https://console.groq.com

3. Run locally:
```bash
npm run dev
```

4. Open http://localhost:3000

## Deploy on Vercel

1. Go to https://vercel.com → New Project → Import this repo
2. Add Environment Variable: `GROQ_API_KEY` = your key
3. Deploy
